Motion Specification Reference

Drill-in (Page Enter)

Duration: 300ms · Curve: Decelerate · Transform: translateX(24px) → 0 · Opacity: 0 → 1

Drill-out (Page Exit)

Duration: 250ms · Curve: Accelerate · Transform: 0 → translateX(-24px) · Opacity: 1 → 0

Popup / Flyout Enter

Duration: 300ms · Curve: Decelerate · Transform: scale(0.95) → 1 · Opacity: 0 → 1

Connected Animation

Duration: 300ms · Curve: Standard · Element morphs position + size between source & destination

Press Feedback

Duration: 100ms · Curve: Decelerate · Transform: scale(0.98) · Instant on pointer-down

Entrance Stagger

Per-item: 300ms Decelerate · Delay: 50ms × index · translateY(20px) → 0 · Opacity: 0 → 1

Confirm Action

This is a ContentDialog following FD1 specifications: Smoke overlay (rgba(0,0,0,0.3)), Elevation 64 shadow, scale 0.95→1 entrance with 300ms Decelerate curve. The dialog traps focus and supports Escape key dismissal.

Connected Animation

The element smoothly transitions from its thumbnail position in the grid to this detail view. In native UWP/WinUI, this uses ConnectedAnimationService with PrepareToAnimate() and TryStartConnectedAnimation(). The motion follows the Standard easing curve over 300ms, maintaining visual continuity between list and detail contexts.
